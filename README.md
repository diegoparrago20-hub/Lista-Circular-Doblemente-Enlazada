# Lista-Circular-Doblemente-Enlazada
Proyecto realizado en Java utilizando NetBeans, correspondiente a la actividad de Lista Circular Doblemente Enlazada. Se desarrolla una interfaz gráfica con Java Swing para representar las operaciones de una lista de boletos.

# Objetivo
Diseñar una interfaz gráfica que permita organizar las operaciones de inserción, eliminación, búsqueda, visualización y navegación circular de boletos.

# Tecnologías utilizadas
Java
Java Swing
Apache NetBeans
Git y GitHub

# Características
Captura de datos de los boletos.

Campos para folio, evento, precio y fecha.

Botones para insertar al principio, al final y por posición.

Botones para remover al principio, al final y por posición.

Opciones para mostrar y buscar boletos.

Navegación circular mediante los botones Anterior y Siguiente.

Tabla para visualizar los boletos.

Interfaz gráfica organizada mediante paneles.

#Estructura del proyecto
Record Boleto: representa los datos de cada boleto, como folio, evento, precio y fecha.

Nodo: almacena un boleto y las referencias al nodo anterior y al siguiente.

ListaCircular: implementa las operaciones de inserción, eliminación, búsqueda y recorrido circular.

Interfaz gráfica: permite interactuar con la lista mediante formularios, botones y una tabla.

# Interfaz gráfica
La interfaz se realiza en NetBeans mediante componentes de Java Swing, organizando los campos y botones para facilitar el uso de las operaciones de la lista.
